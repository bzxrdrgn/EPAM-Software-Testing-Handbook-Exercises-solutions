# EPAM-Software-Testing-Handbook-Exercises-solutions
This is a solutions bank for exercises given in the EPAM's Software Testing Hanbook by Sviatoslav Kulikov 3rd edition

The solution bank contains all solutions to the exercises starting from the Exercise 1.1a

This solution bank is not intended as a tool to cheat but to help students to evaluate their own work.
If you encounter any mistakes or errors in the code, please, contact me to get it edited.
